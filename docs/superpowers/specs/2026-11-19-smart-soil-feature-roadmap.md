# Smart Soil — Feature Roadmap (spec)

สถานะเริ่มต้น (19 พ.ย. 2026): UI ต้นแบบ 39 หน้า ทุกหน้าอ่านจาก `Mock` ใน `lib/data/mock_data.dart`,
ไม่มี package ภายนอก, ไม่มีการเก็บข้อมูลจริง, ยังไม่เชื่อมเครื่องวัด / GPS / backend

## หลักการเรียงลำดับ

1. **ข้อมูลต้องมาก่อนฟีเจอร์** — ทุกฟีเจอร์ (ปุ๋ย อากาศ บันทึกกิจกรรม AI) ต้องอ่านฟาร์ม/แปลง/ผลวัดจริง
   ถ้าทำฟีเจอร์ก่อนชั้นข้อมูล จะต้องรื้อทำใหม่ทั้งหมด
2. **ออฟไลน์ก่อนออนไลน์** — เกษตรกรใช้กลางไร่ เน็ตไม่แน่นอน ฟีเจอร์ที่ไม่ต้องใช้เน็ตทำก่อน
3. **ทีมเครื่องวัดดินทำคู่ขนานได้** ตั้งแต่จบ Phase 1 เพราะ Phase 1 ให้ API `FarmRepository.addRound(...)` สำหรับบันทึกผลวัด
4. แต่ละ phase จบแล้วแอปต้องรันได้ ทดสอบผ่าน และ demo ได้เอง

## Phases

| Phase | ชื่อ | ต้องรอ | ประมาณ (วันทำงาน) | ทำเสร็จเมื่อ |
|---|---|---|---|---|
| 1 | ชั้นข้อมูล + เก็บข้อมูลในเครื่อง | — | 3–4 | สร้าง/แก้/ลบ ฟาร์มและแปลงได้จริง ปิดแอปเปิดใหม่ข้อมูลยังอยู่ |
| 2 | คำนวณปุ๋ยจากผลวัด | 1 | 2 | เลือกแปลง → เห็นปริมาณปุ๋ยต่อไร่และต้นทุน จากผลวัดรอบล่าสุด |
| 3 | แผนที่จริง + GPS | 1 | 3–4 | วาดขอบเขตบนแผนที่ OSM (`flutter_map`) ด้วยพิกัดจริง พื้นที่คิดเป็นไร่จริง |
| 4 | พยากรณ์อากาศรายแปลง | 3 | 1–2 | หน้า Home แสดงฝน/อุณหภูมิ 7 วันจาก Open-Meteo + คำเตือน "อย่าใส่ปุ๋ยก่อนฝน" |
| 5 | บันทึกกิจกรรม + ต้นทุน/กำไร + ปฏิทินเตือน | 1 | 3 | จดกิจกรรมต่อแปลง สรุปต้นทุน-รายได้ และแจ้งเตือนในเครื่อง |
| 6 | ผู้ช่วย AI จริง | 1 (+backend) | 3 | หน้า AI ตอบโดยอิงผลวัดจริงของแปลง ผ่าน backend proxy (ห้ามฝัง API key ในแอป) |
| 7 | บัญชีผู้ใช้ + ซิงก์คลาวด์ + PDF | 1, 6 (backend เดียวกัน) | 4–5 | login, ข้อมูลซิงก์ข้ามเครื่อง, ส่งออก PDF จริง |
| 8 | เสริม (เลือกทำ) | 3 | — | NDVI ดาวเทียม, คาร์บอนในดิน, ราคาพืชผล, สั่งงานด้วยเสียง |
| คู่ขนาน | เชื่อมเครื่องวัดดิน (BLE) | 1 | ทีมฮาร์ดแวร์ | หน้า Measure* ส่งค่าจริงเข้า `addRound` |

**ลำดับที่แนะนำถ้าเวลาจำกัด (Hackathon):** 1 → 2 → 3 → 4 แล้วค่อย 5/6 — 4 phase แรกให้ demo ที่ "ครบวงจร"
(วัด → เก็บ → แนะนำปุ๋ย → ดูอากาศ) โดยไม่ต้องมี backend

## Requirements ของ Phase 1 (ละเอียด — plan อยู่ที่ `docs/superpowers/plans/2026-11-19-phase1-data-foundation.md`)

- R1 ฟาร์ม: สร้าง, แก้ไข (ชื่อ ผู้ดูแล ตำแหน่ง หมายเหตุ แจ้งเตือน), ลบ (ลบแปลงและผลวัดของฟาร์มนั้นด้วย)
- R2 แปลง: สร้าง (ฟาร์ม ชื่อ พืช หมายเหตุ ขอบเขต ≥ 3 จุด), แก้ไข, แก้ขอบเขต, เก็บถาวร/กู้คืน, ลบ (ลบผลวัดด้วย)
- R3 ผลวัด: เก็บรอบการวัด (เวลา + รายการจุด พร้อม Reading) ต่อแปลง; สถานะแปลง = สถานะแย่ที่สุดของจุดในรอบล่าสุด
- R4 เก็บลงไฟล์ JSON ในเครื่อง, เปิดแอปครั้งแรกใส่ข้อมูลตัวอย่างจาก `Mock`, ครั้งต่อไปอ่านจากไฟล์
- R5 หน้าที่ต้องอ่าน/เขียนข้อมูลจริง: FarmList, PlotList, PlotDetail (หัวการ์ด ตัวเลขสรุป แท็บประวัติ),
  CreateFarm, CreatePlot, DrawBoundary, EditPlot
- R6 หน้าอื่น (Home, SoilMap, AI, Measure*, Device*, Plan*) ยังใช้ `Mock` ได้ — ย้ายใน phase ถัดไป
- R7 ไม่เพิ่ม state-management package; ใช้ `ChangeNotifier` + `InheritedNotifier`
- R8 package ใหม่ที่อนุญาต: `path_provider` เท่านั้น
- R9 `flutter analyze` ไม่มี issue และ `flutter test` ผ่านทั้งหมด รวม test เดิม "Every catalog screen builds"

## Requirements ของ Phase 2 — คำนวณปุ๋ยแบบผู้เชี่ยวชาญยืนยัน (ตัดสินใจ 19 พ.ย. 2026)

ผู้ใช้เลือกทางที่สอดคล้องกับหลักการโครงการ: แอป **ไม่ฝังตัวเลขอัตราปุ๋ยใด ๆ ในโค้ด** — ตัวเลขทั้งหมดมาจาก
"ตารางอัตราปุ๋ย" ที่ทีม/ผู้เชี่ยวชาญกรอกในแอป (เช่นจากค่าแนะนำของกรมพัฒนาที่ดิน) และผลคำนวณต้องบอกเสมอว่ายืนยันแล้วหรือยัง
plan: `docs/superpowers/plans/2026-11-19-phase2-fertilizer.md`

- F1 ตารางอัตราปุ๋ยต่อชนิดพืช (crop ตรงกับ `PlotRecord.crop`): สำหรับแต่ละธาตุ N / P / K กำหนด
  เกณฑ์ `lowBelow`, `highFrom` (mg/kg) และอัตรา `rateLow` / `rateMedium` / `rateHigh`
  หน่วย **กก. N, P₂O₅, K₂O ต่อไร่**; มีช่อง "แหล่งอ้างอิง"; ธาตุไหนไม่กำหนดก็ข้ามได้
- F2 ระดับ: ค่าเฉลี่ยรอบล่าสุด `< lowBelow` → ต่ำ, `>= highFrom` → สูง, อื่น ๆ → ปานกลาง
- F3 แปลงเป็นปุ๋ยเดี่ยว: ยูเรีย 46-0-0, ทริปเปิลซูเปอร์ฟอสเฟต 0-46-0, โพแทสเซียมคลอไรด์ 0-0-60
  (กก./ไร่ = อัตรา ÷ เปอร์เซ็นต์) และรวมทั้งแปลง = × พื้นที่ (ไร่)
- F4 ราคาปุ๋ยต่อ กก. (3 ชนิด) กรอกได้; ไม่ได้กรอก (0) → ไม่แสดงต้นทุน (ไม่แสดง 0 บาท)
- F5 การยืนยัน: ผู้เชี่ยวชาญกด "ยืนยันตาราง" พร้อมใส่ชื่อ → เก็บชื่อและเวลา; **แก้ตารางเมื่อไหร่ การยืนยันหายทันที**
- F6 หน้าผลคำนวณแสดงเสมอ: "N-P-K เป็นค่าประมาณ ยังไม่สอบเทียบ" และสถานะตาราง (ยืนยันโดย … / ยังไม่ผ่านการยืนยัน) + แหล่งอ้างอิง
- F7 ไม่มีผลวัด / ไม่มีตารางของพืชนั้น → อธิบายและพาไปหน้าที่แก้ได้ ไม่แสดงตัวเลข
- F8 ข้อมูลไฟล์ Phase 1 (schemaVersion 1) ต้องเปิดได้ไม่หาย (ย้ายเป็น v2 อัตโนมัติ)
- F9 README: แก้หลักการ "ไม่ให้คำแนะนำปุ๋ย" เป็น "คำแนะนำปุ๋ยคำนวณจากตารางที่ผู้เชี่ยวชาญยืนยันเท่านั้น และแสดงคำเตือนเสมอ"
- F10 ไม่มีระบบบัญชีผู้ใช้ — ใครก็กดยืนยันได้ (บันทึกชื่อที่พิมพ์); สิทธิ์จริงรอ Phase 7
- พื้นที่ (ไร่) ยังมาจากแผนที่ตัวอย่างจนกว่าจะทำ Phase 3 (GPS) — หน้าผลต้องบอกว่าเป็นพื้นที่โดยประมาณ
